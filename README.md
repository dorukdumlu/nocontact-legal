# NoContact · Legal

Privacy Policy and Terms of Service for the **NoContact** mobile
app, served via GitHub Pages so both documents have stable public
URLs that can be linked from:

- the in-app Settings screen (required by Google Play), and
- the Play Console store-listing form (also required).

## Live URLs

- Landing:        https://dorukdumlu.github.io/nocontact-legal/
- Privacy Policy: https://dorukdumlu.github.io/nocontact-legal/privacy-policy.html
- Terms of Service: https://dorukdumlu.github.io/nocontact-legal/terms.html

## Updating

Edit the `.html` files in place, commit, and push. GitHub Pages
rebuilds the site within about a minute — no build step, no
framework, plain HTML + inline CSS by design so nothing can break
between Google's reviewer clicking the link and the page loading.
